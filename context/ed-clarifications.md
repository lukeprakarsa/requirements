## #786: Can 2000-Level Courses satisfy the 1000 Level Technical Elective Requirement?

- Category: Undergraduate – Requirements
- Asked by: Anonymous, about Oct 22, 2026 (shown as "3 weeks ago" on Nov 12)
- Answered by: Kathi Fisler (DUS/DMS); the accepted answer
- Captured: Nov 12, 2026, from Luke's screenshot

> **Question:** Or does the Technical Elective Requirement only allow using 1000-level courses?
>
> **Answer:** If those 2000-level courses are also Technical, then yes.

What it settles: a 2000-level CSCI course can fill a CSCI Technical Elective slot unless it is a
non-technical course. Bulletin footnote 3 on that slot: "None of these can be CS non-technical
courses. The list of these is in the concentration handbook."
